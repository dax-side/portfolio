# Damola Adegbite — Fullstack Developer Portfolio

Personal portfolio website for Damola Adegbite, a Fullstack Engineer specializing in React, Node.js, and TypeScript. 

## Tech Stack
- **Frontend**: React, Vite
- **Styling**: Custom CSS & Design Tokens
- **Hosting**: GitHub Pages

## Deployment
This project is configured to automatically deploy to GitHub Pages via GitHub Actions (`.github/workflows/deploy.yml`) whenever changes are pushed to the `main` branch.
